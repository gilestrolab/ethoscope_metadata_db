How owners are found

Each run has at most one owner: the person whose experimenter name was typed on the node, otherwise the one person who owns the metadata files that describe it. A metadata file belongs to the person whose home folder it is in. Names marked as not a person (guest accounts, shared or project folders) own nothing, and a run described by files of two different people is left without an owner.
